# Gloria Sarah Saragih — GitHub Pages Portfolio

A clean, neutral, reusable personal portfolio website for job applications.

## Files

- `index.html` — main portfolio page
- `style.css` — neutral responsive styling
- `script.js` — mobile navigation, expandable cards, and experience filters

## How to publish on GitHub Pages

1. Create or open the repository: `glosarah.github.io`.
2. Upload/replace these files in the root of the repository:
   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md` (optional)
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Save and open `https://glosarah.github.io` after deployment finishes.

## Notes

- The page intentionally avoids mentioning any specific company or application program.
- The design uses neutral colors and standard readable typography.
- Documents and projects are linked externally through Google Docs, Google Drive, Canva, Google Sheets, and Looker Studio.


## Color options

Default palette in `style.css`: **Soft Slate** — clean gray-blue, professional, and safe for general job applications.

Additional palette files are included:

- `style-warm-gray.css` — warmer beige-gray, still muted and professional.
- `style-ink.css` — almost black-and-white, most minimal.
- `style-soft-blue.css` — subtle blue-gray, a little softer and more polished.

To use another palette, rename the chosen file to `style.css`, replacing the current one.
